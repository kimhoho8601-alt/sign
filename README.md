# Sign Studio

이름 입력 또는 자필 서명 이미지를 기반으로 3가지 스타일의 서명을 만들고, 선택한 결과를 **투명 PNG**로 저장하는 정적 웹앱입니다.

## 주요 기능

- 이름/문구 입력 → 인장형, 유려한 사인, 빠른 필기형 3안 생성
- 자필 사인 이미지 업로드 → 배경 제거 및 3가지 보정안 생성
- 배경 제거 강도 조절
- 선택 결과 자동 여백 정리 후 투명 PNG 다운로드
- 지원 브라우저에서 PNG 클립보드 복사
- 개인정보 서버 전송 없음: 모든 처리는 브라우저에서 수행

## 실행

별도 빌드 과정이 없습니다. `index.html`을 열거나 GitHub Pages에서 루트 디렉터리를 배포하면 됩니다.

## 디자인

기존 family-tree 프로젝트의 레드/화이트 시스템을 이어 사용합니다.

- Red: `#c9002b`
- Dark Red: `#9d0022`
- Ink: `#241b1d`
- Paper: `#fffdfd`
- Page: `#f7f3f4`

## 파일

- `index.html` — 화면 구조
- `styles.css` — 반응형 UI 및 디자인
- `app.js` — 서명 생성, 이미지 보정, 투명 PNG 출력
